# Frameworks

Frameworks hold versioned legal, regulatory and management-system knowledge consumed by skills and workflows.

Planned framework directories:

- `gdpr/`
- `iso27701/`
- `eu_ai_act/`

A framework should expose structured rules with jurisdiction, authority, source identifiers, effective dates and verification metadata. Framework content must not be copied blindly from third-party skill repositories.

The legal-source registry and verification policy in `legal_sources/` govern promotion of framework rules into production use.
