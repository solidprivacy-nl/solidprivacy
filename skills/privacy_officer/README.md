# Privacy Officer Skills

Reusable privacy-officer task skills. These are building blocks for workflows, not substitutes for professional judgement.

Planned skill directories:

- `dsar/`
- `dpia/`
- `ropa/`
- `breach_assessment/`
- `retention/`
- `vendor_assessment/`
- `international_transfers/`
- `ai_privacy_assessment/`

Initial production priority: DPIA, DSAR, RoPA and breach assessment.

Each skill must separate workflow logic from legal/framework knowledge, emit evidence-backed structured output, classify legal claims, expose uncertainty and define explicit human-review gates.
