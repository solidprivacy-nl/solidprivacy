# Workflow — Document to DPIA

Status: governed analysis implemented through WP5.

```text
SCRUBBED / MINIMISED INPUT
  -> evidence registration
  -> model-call privacy policy gate
  -> candidate fact extraction
  -> provenance validator
  -> contradiction + missing-information gate
  -> deterministic evidence readiness
  -> pre-scan / DPIA-necessity decision support
  -> governed legal-context resolver
  -> structured DPIA analysis/draft
  -> traceability validator
  -> Privacy Officer review
  -> scrubbed report
  -> controlled reinsert handoff
```

Current executable coverage: WP1 canonical processing/DPIA contracts; WP2 pre-scan/legal-decision/integrity gates; WP3 evidence/fact provenance/readiness; WP4 safe AI-call boundary + fact detector/validator; WP5 curated legal rules, jurisdiction/freshness resolver and source/fact-traceable DPIA draft validator.

`Scrubbed` is not equivalent to anonymous. External calls require approved model policy and direct identifiers/Scrub Key remain outside the boundary. The model does not select legal authority. Non-final consultation material may be forward context but cannot support legal claims. Provenance validation is not human acceptance; unreviewed facts remain explicit. Final residual-risk acceptance and material legal conclusions remain Privacy Officer/DPO decisions.
