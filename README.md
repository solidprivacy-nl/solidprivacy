# SolidPrivacy

Controlled AI workflow library for privacy-officer and privacy-document processing tasks.

This repository separates:

- reusable document-processing and privacy-officer skills;
- versioned legal and governance frameworks;
- auditable end-to-end workflows;
- machine-readable input/output/evidence contracts;
- synthetic, regression and legal-accuracy evaluations;
- authoritative legal-source governance; and
- third-party provenance and licensing.

## Architecture

See [`docs/architecture.md`](docs/architecture.md) for the repository architecture, safety model, common execution contract and intended integration with SolidPrivacy Scrub.

## Initial workflow priority

The first production-oriented tranche is intentionally limited to:

1. DPIA;
2. DSAR;
3. RoPA;
4. breach assessment.

Third-party privacy/GRC skill libraries are treated as raw material. Their legal assertions are not authoritative until independently verified against approved sources and covered by evaluations.
