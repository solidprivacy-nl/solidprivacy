# Methodologies

Assessment and risk methodologies live here independently of prompts and legal-source text.

## Initial methodology adapters

- `nl_rijksmodel_dpia/` — Dutch Government DPIA/pre-scan model;
- `edpb_dpia/` — EDPB DPIA template/meta-template direction;
- `cnil_pia/` — CNIL PIA methodology comparison;
- `nist_pram/` — NIST privacy-risk methodology.

A methodology defines assessment structure, questions, stages, scoring or decision logic. It does not automatically define what is legally mandatory.

Each implementation must declare:

- source and version;
- jurisdiction/relevance;
- lifecycle status (final, draft, consultation, deprecated);
- machine-readable source if available;
- legal claims it depends on;
- human-review points;
- mapping to canonical vocabulary.
