# DPV adapter

Status: architecture placeholder; no DPV content vendored yet.

Reference:

- `https://github.com/w3c-cg/dpv`
- `https://w3id.org/dpv`

## Initial mapping scope

Prefer mappings for concepts including:

- personal data and data categories;
- purposes;
- processing operations;
- controller, processor, data subject and recipient roles;
- legal bases;
- rights;
- risks;
- technical and organisational measures;
- technologies.

## Rules

- DPV provides semantics, not legal authority;
- exact reuse/license terms must be checked before vendoring content;
- mappings need regression tests;
- SolidPrivacy may retain narrower product-specific identifiers with explicit mapping metadata.
